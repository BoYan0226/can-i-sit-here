# Can I Sit Here?

An interactive reading adapted from Bo Yan's *Can I Sit Here?*.

Open `index.html` in a browser or serve this directory as a static website. There is no build step or external runtime dependency.

The four New York Public Library steps photographs are by William Fortunato, via Pexels. They appear in black and white through CSS filters; the source image files are preserved in color. Photo sources: [group conversation](https://www.pexels.com/photo/content-multiethnic-friends-sitting-on-stairs-6140437/), [coffee conversation](https://www.pexels.com/photo/cheerful-diverse-men-with-coffee-to-go-sitting-on-stairs-6140430/), [close conversation](https://www.pexels.com/photo/happy-multiracial-male-friends-sitting-on-stairs-in-street-6141093/), and [coffee detail](https://www.pexels.com/photo/crop-multiethnic-men-with-coffee-sitting-on-steps-6140428/).
